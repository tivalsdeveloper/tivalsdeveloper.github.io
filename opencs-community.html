GitHub actions through the Telegram bot

In the OpenCS Telegram group, send a command or mention the bot as required. Follow the bot's prompts to select a repository before performing an action.

1

Send /github to start GitHub tools and choose an existing repository or create a repository.

2

Choose the file action to create files or folders, upload content, open and read files, or edit an existing file. Review the target path and changes before submitting.

3

To publish a project to the community, create or select a repository and add a clear README with setup instructions.
