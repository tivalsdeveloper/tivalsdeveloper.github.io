Getting started

Ready in a few steps.

The APK is the app installer. AI model files are separate downloads, so you can decide when to add offline features.

Prefer a browser? Open Tivals AI ↗
  1. Download your APK

    Choose 64-bit for most modern phones, or 32-bit if your Android system requires it.

  2. Open the downloaded file

    Tap the APK in Downloads. If Android asks, allow your browser or Files app to install this app, then tap Install.

  3. Launch Tivals AI

    Open the app and use online chat, or switch to Offline mode for private local chat.

  4. Set up your offline model

    Use “Scan for models” to reuse a compatible file, or download the model selected for your phone. Allow enough free storage and use Wi-Fi for model downloads.

Good to know

Which offline text model will my phone use?

Low-memory phones use SmolLM2-360M-Instruct Q4_K_M. Standard-tier phones use Qwen2.5-0.5B-Instruct Q4_K_M. The app detects the memory tier automatically; there is no model picker. The APK does not include these model weights.

Can I generate images offline?

Image generation is experimental on standard-tier phones. It uses a separate model downloaded when the feature is used, requiring approximately 1.55 GB of storage for the model alone. Image generation is disabled on low-memory phones in this release.

What if the phone is low on memory or gets hot?

The app can stop or pause generation when memory is low or the phone gets hot. Close other apps and let the phone cool before continuing. Device testing is still needed; these builds do not carry a guarantee against crashes or overheating.

How do permissions and privacy work?

Grant only the device access you want to use. Offline tool results are kept on the device. Review access in the app’s permissions screen, and revoke Android permissions in your phone’s Settings. Online chat uses the website’s normal online AI service.
