Connect your Telegram bot

1. Create it with BotFather

  1. Open the verified @BotFather account and send /newbot.
  2. Choose a name and a unique username ending in bot.
  3. Copy the token privately. Treat it as a password.

2. Connect and configure

  1. Open the Tivals AI Telegram dashboard with /app.
  2. Open Accounts & tools, select Personal bot or Business bot, and paste the token.
  3. Save its name, purpose, and instructions in Bot Studio. Business owners can add business details in the Business tab.
  4. Open your bot and send /start to test it.

Never paste a bot token into a public chat or GitHub file. Connected account tools such as GitHub and Gmail are for the bot owner.

How to use @ tools

Type @ to see available tools, or send @tool your request. Connect accounts with /connect before using private tools. Tool availability depends on which bot and accounts you have connected.

@github

Browse a repository, read code, create files or issues, and request code changes. Changes to repositories may ask you to confirm before they are made.

@github list files tivalsdeveloper/tivals-aiSee all GitHub examples

@gmail

Read connected mail and prepare replies. Sending requires your confirmation.

@gmail check my latest emails

@web and @ai

Search current information or ask your assistant for help.

@web latest Python release@ai explain Python loops simply

@youtube

Find videos and open their Telegram previews or links.

@youtube Python beginners tutorial

@image

On the main Tivals AI bot, describe an image to generate. On a connected personal bot, attach a photo and ask about it.

@image a blue robot in a classroom

Other tools

On connected bots, try @website, @voice, @reminder, or @tutor. The main bot also offers connected TikTok tools. Send /tools in the bot for its current list.

@reminder remind me tomorrow at 8 AM to study

How to use / commands

Start a message with a slash. Send /help or /tools for commands supported by the bot you are chatting with.

CommandWhat it doesExample
/startStart the bot and see its welcome message./start
/help, /toolsSee commands and tool examples./tools
/appOpen the Mini App dashboard to manage your bot./app
/connect, /accountsConnect accounts or check connections./accounts
/github, /gmailOpen help for GitHub or Gmail tools./github
/youtube, /searchFind videos or information./youtube Python tutorial
/lesson, /explain, /quiz, /practiceLearn and practice a subject in a connected bot./quiz fractions
/remind, /remindersSet and view reminders on supported bots./remind tomorrow 8 AM study
/storeBrowse available published products./store Python book
/grouphelpSee how to use an owned bot in groups or channels./grouphelp

Many @ tools also work with / on the main Tivals AI bot. Some commands differ on bots that users connect themselves.

GitHub examples

Connect GitHub first using /connect. Replace owner/repository with a repository you can access, and use a real name instead of NAME. For file paths, include the full path from the repository root.

Inspect a repository

@github inspect tivalsdeveloper/tivals-ai@github list files tivalsdeveloper/tivals-ai@github list files tivalsdeveloper/tivals-ai:src@github read file tivalsdeveloper/tivals-ai:README.md

Create or change code

@github create file owner/repository:notes.txt containing Project notes@github add to file owner/repository:notes.txt | New exact line to add@github fix code owner/repository:src/app.js to handle empty input

Repositories and issues

@github create repository my-project as private@github create issue in owner/repository | Login button fails | Clicking Sign in does nothing

Creation and editing need write access to the selected account or repository.

Upload a document

Send a document to the main Tivals AI bot with this caption. Use a specific destination filename.

@github upload owner/repository:docs/guide.pdf

Use /github for help if an action is unavailable in your connected bot.
